# Imagens para o LinkedIn

Capturas reais do aplicativo ([demo](https://tabela-periodica-3d-six.vercel.app/)), geradas por `npm run qa` (câmeras fixas, transições concluídas, 1920×1004). Nenhuma imagem foi editada ou gerada por IA.

Ordem sugerida para o carrossel:

| # | Arquivo | O que mostra |
|---|---------|--------------|
| 1 | [`linkedin-capa-01.png`](linkedin-capa-01.png) | **Capa.** Vista em diagonal da instalação inteira: os 118 módulos de MDF com placas de acrílico, a placa informativa com os QR Codes e a caixa dos 4 botões arcade. |
| 2 | [`linkedin-geral-02.png`](linkedin-geral-02.png) | Vista frontal completa, como o visitante encontra a tabela no ambiente. |
| 3 | [`linkedin-elemento-04.png`](linkedin-elemento-04.png) | O módulo do Ouro (Au) retirado do nicho, mostrando a peça de acrílico e o braille. |
| 4 | [`linkedin-explodida-06.png`](linkedin-explodida-06.png) | Vista explodida: as camadas de cada módulo (MDF, acrílico, LED) separadas. |
| 5 | [`linkedin-acessibilidade-08.png`](linkedin-acessibilidade-08.png) | Guia de acessibilidade com braille visual e as opções da interface. |

A sequência vai do todo (capa e vista geral) ao detalhe (um elemento, como é montado) e termina na acessibilidade, que é o propósito do projeto.

As demais capturas (`perspectiva-03`, `detalhe-05`, `interface-07`, `botoes-09`, celular) são geradas na pasta `capturas/` pelo mesmo script e ficam fora do post para não repetir ângulos.
